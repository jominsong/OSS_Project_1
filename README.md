# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 (누르고 있으면 연속 발사) |
| R | 게임 오버 후 다시 시작 |
| Esc | 게임 중 일시정지 / 일시정지 중 다시 누르면 이어서 진행 / 게임 오버 화면에서는 메인 메뉴로 / 시작 화면에서는 종료 |
| ↑ / ↓, Enter | 일시정지 메뉴에서 항목 선택·실행 — `Resume`(계속하기), `Main Menu`(시작 화면으로), `Quit`(종료) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |

| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |

## 구현한 기능

- [x] F1 플레이어 이동 — ←/→ 키를 누르고 있는 동안 `PLAYER_SPEED`만큼 이동, 화면 좌우 끝 밖으로 나가지 않음
- [x] F2 총알 발사 — Space로 플레이어 위쪽 가운데에서 총알 발사, 위로 날아가 화면 밖으로 나가면 제거, 게임 오버 중에는 발사 안 됨
- [x] F3 적 명중과 점수 — 총알과 적이 부딪히면 둘 다 제거되고 적 하나당 10점, 왼쪽 위에 `SCORE: N` 표시
- [x] F4 피격과 게임 오버 — 적이 닿거나 화면 아래로 지나가면 생명 1 감소, 생명 0이면 게임 오버(`GAME OVER`와 이번 판 점수 표시)
- [x] F5 재시작과 최고 점수 — 게임 오버에서 R로 재시작, 최고 점수를 `highscore.txt`에 저장해 다시 실행해도 유지, `HIGH SCORE`와 `Press R to restart` 표시

> `highscore.txt`는 게임을 하면 자동으로 생기는 파일이라 `.gitignore`로 저장소에서 제외했습니다.

## 추가한 기능 (개조)

F1–F5 규칙은 그대로 두고 그 위에 얹은 기능입니다. 수치는 모두 `settings.py`에서 바꿀 수 있습니다.

- **일시정지 메뉴** — Esc로 일시정지, `Resume` / `Main Menu` / `Quit` 선택. 일시정지 중에는 적·배경·타이머가 모두 멈춤
- **연속 발사** — Space를 누르고 있으면 `FIRE_INTERVAL`(9프레임)마다 추가 발사. 한 번만 누르면 한 발
- **사냥 구간과 파워업** — 게임 시작 후 `HUNT_SECONDS`(20초) 동안 적을 잡을 때마다 파워업 레벨이 1씩 오름(최대 `POWER_MAX` = 4). 화면 위에 `HUNT` 남은 시간과 `POWER` 표시
- **다발 사격** — 한 번에 나가는 총알 수 = 1 + 파워업 레벨(최대 5발). 총알은 서로 겹칠 만큼 촘촘하게 나감(`BULLET_SPREAD`). 일반 적 처치 점수는 파워업과 무관하게 항상 10점
- **흔들리는 적** — 좌우로 출렁이며 내려오는 붉은 적 `WaveEnemy`. 파워업 레벨이 높을수록 나올 확률이 커짐(40% → 최대 80%)
- **놓치면 페널티** — 적이 화면 아래로 지나가면 생명 1과 파워업 레벨 1이 함께 줄어듦
- **시작 생명 10** — 스타터는 3이었는데 위 페널티를 감안해 `START_LIVES`를 10으로 늘림
